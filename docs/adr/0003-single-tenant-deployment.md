# Single-tenant deployment: one forum per Cloudflare deployment

Each web master clones Project F and deploys it to their own Cloudflare account; there is no centralized multi-tenant infrastructure shared across forums. Every deployment is exactly one forum with its own domain, owned and managed by the web master: they own the domain, and Cloudflare handles DNS and automatic TLS. Project F is domain-agnostic — it serves whatever host it is configured with. A forum can go live on the subdomain Cloudflare provides at deploy time and later point its own domain at it. We chose this over a hosted multi-tenant SaaS because Project F is meant to be deployed by each community owner like classic forum software (phpBB, MyBB), which keeps ownership and data in the community's hands.
